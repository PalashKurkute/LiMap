# LiMap implementation plan: blueprint, roadmap, next steps

Status as of 2026-10-05. Done = built and backed by a results file or test. Partial = built, a stated gap remains. Open = not built.
Numbers: `benchmark/*.json` only. Labels: MEASURED, CALCULATED, EXTERNAL (not ours). History: git tag `docs-before-consolidation`.

## A. Original blueprint (Sep 2026, Phases 0-10, condensed)

Goal: SIH26053 (DRDO), win on rigour: real pretrained models, off-road and Indian classes, per-cell uncertainty, a quantified memory demo. Build order: pretrained segmentation + grid + memory dashboard, then MOS + ghost removal + off-road fine-tuning, then Jetson/TensorRT last. Five intended differentiators: speed/heading fovea (Partial: presets), dual-elevation overhang band (Done), Indian + off-road 12 classes (Open), planner regret with per-ring memory (Partial), degraded-sensor stress tests (Partial).

Stack (planned, then built): I/O numpy.fromfile/open3d (built: numpy, optional mmap, `.bin`/`.label` only). Odometry kiss-icp (optional extra; NumPy ICP fallback runs). Ground pypatchworkpp (not used; PCA patch planes). Backbone SalsaNext/RandLA-Net ONNX + TensorRT FP16 (SalsaNext ONNX on CPU; published SalsaNext 59.5% mIoU @ 24 FPS is EXTERNAL). Arrays NumPy 2 + Numba + CuPy (Numba only). Grid: custom nested lattice 1:2:5:10, preallocated hash (built). Anti-ghost FreeDOM + Kalman (ray-march eraser + 4-state tracker). Planner Hybrid-A*/Reeds-Shepp (Hybrid-A*, Ackermann). Backend FastAPI + WebSockets (built; `/ws/stream` exists, client unused). Dashboard React + Vite + deck.gl + Three.js (no deck.gl).

- **P0 Environment, data, synthetic lab.** Specs: pin deps; stage SemanticKITTI 00/07, RELLIS-3D 00000-00004, IDD-3D Hyderabad subset, SalsaNext + RandLA-Net weights; `data/generate_synthetic.py` scenes A bridge (2.5 m clearance, 1.0 m deck), B potholes (25 cm deep, 50 cm wide), C moving vehicle 8 m/s, D thin poles at 5/20/40/70 m. Accept: a stranger runs the tests with no FileNotFoundError. **Partial:** scenes A-D regenerate by script (untracked); seq 08 only (976 scans, gap 108-129, local); no 00/07, RELLIS, IDD, RandLA-Net; ONNX model not in repo; `requirements.txt` omits numba/onnxruntime/pytest.
- **P1 Ingestion, frames, deskew.** Specs: mmap loader, 130k points < 1.5 ms; `.pcd`/`.las`; REP 103 (x fwd, y left, z up) + REP 105 chain; KISS-ICP deskew with per-beam timestamps; baselines 3.2 GB dense / 128 MB uniform 2.5D. **Partial:** loader `.bin`/`.label`; constant-velocity deskew + ICP; baselines are 3,051.8 MB (calculated: 100x100x10 m, 5 cm, 4 B) and 122.07 MB; no `.pcd`/`.las`; ingest 0.004 ms, range projection 19.98 ms mean (edge profile, 123,389 points) vs the 2 ms target.
- **P2 Pretrained segmentation, honest mIoU.** Specs: 64x2048 range image < 2 ms; SalsaNext ONNX/TensorRT, 24+ FPS GPU; 12-class remap (road_smooth 0.05, terrain_rough 0.50, terrain_soft 0.60, vegetation_low 0.25, vegetation_high 0.80, obstacle_vertical 0.90, obstacle_thin 0.95, hazard_negative 0.90, dynamic_vehicle/vulnerable/animal 1.00, overhang_structure = dual-elevation flag); mIoU by 0-10/10-25/25-50/50-100 m; quote RELLIS-3D SalsaNext 43.07%, KPConv 19.07% (EXTERNAL; the RELLIS-3D repo lists 40.20% for SalsaNext). Never demo an untrained model. **Partial:** pretrained SalsaNext ONNX (CPU), 100 frames of seq 08: accuracy 88.96%, mIoU 53.52% over present classes (42.25% over all 20), ring 0/1/2 = 37.96/44.04/30.93%, ring 3 had 0 points (`real_miou_results.json`); 12-class remap not built (SemanticKITTI ids used); no GPU/TensorRT run.
- **P3 Core grid.** Specs: base 5 cm, k = 1/2/5/10, rings 0-10/10-25/25-50/50-100 m (blueprint's 10-30/30-60/60-100 was superseded); coarse cell = integer block, 4M boundary probes, 0 mismatches; Welford + Chan, uncertainty-preserving coarsening (min/max/variance), Kalman with R(r) = s0^2 + a r^2; 32 B cells in a preallocated flat array, Morton order, bound < 3.5 MB; per-ring memory report. **Done** except: 106,875 cells x 32 B = 3,420,000 B = 3.2616 MB; seam test `benchmark/test_phase3.py`; per-ring split is accounting in `core/grid/baselines.py` (40,000/34,875/18,000/14,000 cells), one shared pool; Chan merge lives in `coarsen_cells` (tests only call it); Kalman not wired (P6); Morton order not built.
- **P4 Dual elevation + negative hazards.** Specs: ground = lowest dense cluster; ceiling = min z above ground + 1.8 m; clearance = ceiling - ground; states Open_Sky / Traversable_Underpass (clearance >= vehicle + margin) / Overhang_Collision; negative hazard z < ground - 0.15 m with depth; a 25 cm x 50 cm pothole must survive at 5 m and 25 m. **Partial:** dual elevation wired into insertion (`spatial_hash.py`, `dual_elevation.py`; 1.8 m vehicle, 0.2 m margin); hazard test is `z_min < -1.95` or variance > 0.08; `negative_hazards.py` and the 5/25 m survival test do not exist.
- **P5 Adaptive fovea.** Specs: inputs speed, heading, curvature, load; ring stretch for v > 5 m/s; turn bending; throttle < 20 Hz / > 30 Hz; hazard score H (fine at H <= 0.25, coarse > 0.80). **Partial:** `fovea_controller.py`, 5 integer-aligned presets (stationary, city, highway, turn left/right); throttle and hazard score not built.
- **P6 MOS + ghost removal.** Specs: residual > 0.3 m/s is dynamic; Bresenham free-space clearing with log-odds, no timeouts; 6-state Kalman tracker, oriented boxes, 1 s prediction. **Partial:** range-disparity 0.35 m after ego compensation, gated by predicted classes; ray-march eraser (strided, resets cells, no log-odds); 4-state [x, y, vx, vy] tracker; 50 real frames precision 61.6%, recall 47.65%, FPR 1.10%, 1,130 tracks, 509 ghost cells (`real_dynamic_mos_results.json`).
- **P7 Indian / off-road fine-tuning.** Specs: IDD-3D box pseudo-labels (17 classes), RELLIS-3D mapping (mud, puddle -> soft; rubble -> rough; tall grass -> low vegetation), `scripts/finetune.py`, class-weighted loss, report vs 59.5% / 43.07% / 19.07% with distance bins. **Open:** only `idd3d_bridge.py` (synthetic boxes); no IDD/RELLIS data, no fine-tune.
- **P8 Planner regret.** Specs: costmap 0-255 + `grid_map_msgs`; Hybrid-A* with clearance penalty; 100-run suite (goals 10-80 m, SemanticKITTI + RELLIS); targets regret < 1.5%, max deviation < 10 cm, collisions 0.0%, > 10x faster collision checks; per-ring memory beside it. **Partial:** costmap + OccupancyGrid bridge; 5 real frames (0, 5, 10, 20, 30): mean 3.45%, max 10.52%, Frechet mean 0.584 m / max 1.626 m (`real_regret_results.json`): targets not met; 3 of 5 frames 0%; labels are dataset ground truth; no 100-run suite, no `grid_map_msgs`, no speed or collision-rate measurement.
- **P9 Dashboard.** Specs: binary WebSocket 30-60 FPS; dual viewport; ghost before/after slider; memory bar (dense 3D vs uniform 2.5D vs ours); cell inspector with z_ground/z_ceiling/clearance; confidence heat-map. **Done differently:** static snapshots + optional API; Three.js 3D view, Map Inspector, uniform-vs-FoveaGrid swipe, Evidence page (3,051.8 / 122.1 / 3.2616 MB, CALCULATED capacities), variance colouring (Welford); no ghost before/after view; the "97.3% saved / 0.0% regret" bar was dropped as wrong.
- **P10 Stress, Jetson, report.** Specs: 10.1 harness: beams 64 -> 32 -> 16, noise sigma 0.2 m + clutter, 50 ms odometry jitter, "degrades predictably, never fails"; 10.2 per-module latency on Orin Nano vs AGX Orin, CPU vs GPU FPS, power at 10 Hz; 10.3 one-slide competitor matrix (-> `docs/reference/COMPETITORS.md`); 10.4 auto-report with per-band mIoU, per-ring memory, regret, FPS, stress matrix (-> Evidence page). **Partial:** `stress_harness.py` has 5 modes (50% dropout, 10 cm noise, ground absorption, 15 m/s, reverse) and checks memory only, no results file; **no Jetson run**: `edge_hardware_profile.json` Jetson/Pi rows are projections scaled from the host baseline, not measurements.

## D. Rules of engagement

1. Every number comes from a script that ran on current code (`benchmark/*.json`); derive ratios where used. Label MEASURED / CALCULATED / EXTERNAL.
2. No absolute claims ("100%", "fully verified"); state scope. No "DRDO bound/threshold", "provably", "near-zero regret"; no competitor names in product docs or the demo narration.
3. Update `docs/reference/KNOWN_LIMITATIONS.md` in the same change that adds or removes a capability.
4. One initiative at a time; then run the tests, `scripts/verify_all_milestones.py`, and the seam test (re-run it for any change to ring boundaries or presets).
5. History lives in git; tag `docs-before-consolidation` holds the pre-consolidation docs and audits. Do not rewrite history.
6. Report failures honestly: a modest real number beats an unverifiable one; keep the old figure when a new one replaces it (baseline 4,069.415 ms stays in `edge_hardware_profile.json`).
7. Never claim Jetson/embedded, IDD-3D, RELLIS-3D, GPU/TensorRT results without that run on that data/hardware.
8. Never quote the 3.19 ms synthetic micro-benchmark as latency; never present 935.7x without "capacity ratio" beside 1.41x occupied; never train a segmentation network from scratch for the pitch.
9. Memory bound: `SpatialHashGrid.cells.nbytes` <= 3,420,000 B (3.2616 MB); no persistent per-frame allocations; do not change the 32-byte cell layout without re-measuring.
10.
